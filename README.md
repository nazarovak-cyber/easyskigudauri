# Easy Ski Gudauri — лендинг

Одностраничный сайт школы горных лыж и сноуборда в Гудаури (Грузия).
Статика без сборки: ни npm, ни билда — файлы публикуются как есть.

## Что внутри

```
index.html   вся страница: разметка, стили, скрипты и переводы RU / EN / KA
img/         фотографии (WEBP) и логотип
vid/         три вертикальных ролика (MP4, H.264)
```

Переключатель языка в шапке меняет тексты без перезагрузки; выбор
сохраняется в localStorage браузера.

## Публикация

**Cloudflare Pages** — подключить этот репозиторий, framework preset: `None`,
build command оставить пустым, output directory: `/`.

**GitHub Pages** — Settings → Pages → Source: ветка `main`, папка `/ (root)`.

**Обычный хостинг** — загрузить содержимое репозитория в корень сайта
(`public_html`), сохранив структуру: `index.html` рядом с `img` и `vid`.

## Важно

Сайт не нужно пересобирать, конвертировать или «улучшать» автоматическими
инструментами — вёрстка рассчитана на эти файлы как есть.
Шрифты подключаются с fonts.googleapis.com.
